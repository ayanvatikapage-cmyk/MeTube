# UltraStream - High Speed Private Media Downloader

A high-performance, private media downloader built with FastAPI, yt-dlp, and modern responsive UI.

## Features
- **YouTube Support:** Multi-resolution picker (1080p, 720p, 480p, 360p, MP3 Audio).
- **TikTok Support:** Clean HD download with **Zero Watermark**.
- **Facebook Support:** Direct HD (1080p/720p) and SD video streams.
- **Direct High-Speed Download:** No queue waiting; streams directly to the browser at maximum bandwidth.
- **Cookie Support:** Easily bypass YouTube cloud bot restrictions.
